#Web-Designing-Workshop

## How You Should Use This Repository

**Do not copy the entire repository into your submission folder.**

First, create **one root folder** for your complete Web Designing Workshop work.

For example:

```text
WD-Workshop-Nitish/
```

Inside this root folder, create **all the HTML files directly**.

Your local structure should look like this:

```text
WD-Workshop-Nitish/
│
├── index.html
├── LOGIN.HTML
├── REGISTRATION.HTML
├── CATALOGUE.HTML
├── CART.html
├── CSE.html
├── AIML.html
├── DS.html
└── IOT.html
```

There should be **no separate `experiment-1`, `experiment-2`, `experiment-3` folders** inside your root folder.

### How to Work

Open this repository:

https://github.com/NitishSolves/Web-Designing-Workshop

Then go to:

```text
experiments/
```

Inside it, the experiments are organized separately for reference:

```text
experiments/
│
├── exp-01-home-page/
│   └── index.html
│
├── exp-02-login-page/
│   └── LOGIN.HTML
│
├── exp-03-catalogue-page/
│   └── CATALOGUE.HTML
│
├── exp-04-cart-page/
│   └── CART.HTML
│
└── exp-05-registration-page/
    └── REGISTRATION.HTML
```

You should **open each experiment one by one** and copy the required HTML code into the corresponding file in your own root folder.

For example:

```text
Repository                               Your Local Folder

exp-01-home-page/index.html       →      index.html

exp-02-login-page/LOGIN.HTML      →      LOGIN.HTML

exp-03-catalogue-page/             →      CATALOGUE.HTML

exp-04-cart-page/                  →      CART.html

exp-05-registration-page/         →      REGISTRATION.HTML
```

### Important

The folders such as:

```text
exp-01-home-page/
exp-02-login-page/
exp-03-catalogue-page/
```

exist **only in this reference repository to keep the experiments organized**.

You **do not need to create those folders locally**.

Your own work should remain directly inside your single root folder:

```text
WD-Workshop-Nitish/
```

Then, experiment by experiment:

```text
1. Create the required HTML file in your root folder.
2. Open the corresponding experiment in this repository.
3. Copy its code.
4. Paste the code into your local file.
5. Modify it according to your lab requirements.
6. Test the file in your browser.
7. Continue with the next experiment.
```

### Example

For Experiment 1:

```text
Your folder:
WD-Workshop-Nitish/
└── index.html
```

Open:

```text
Web-Designing-Workshop/
└── experiments/
    └── exp-01-home-page/
        └── index.html
```

Copy the code from the repository `index.html` and paste it into your own:

```text
WD-Workshop-Nitish/index.html
```

Then repeat the same process for Login, Registration, Catalogue, Cart, and the other required HTML pages.

### Final Submission Structure

Your final local folder should look something like:

```text
WD-Workshop-Nitish/
│
├── index.html
├── LOGIN.HTML
├── REGISTRATION.HTML
├── CATALOGUE.HTML
├── CART.html
├── CSE.html
├── AIML.html
├── DS.html
└── IOT.html
```

**Keep all your HTML files directly inside the root folder unless your teacher specifically asks for another structure.**
