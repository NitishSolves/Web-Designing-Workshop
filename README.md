# Web-Designing-Workshop

## How to Use This Repository

This repository contains the HTML files for the Web Designing Workshop experiments.

### Important: Copy the Complete Experiment Folder

If you want to perform/write a particular experiment, **do not copy only one HTML file**.

Instead, open the folder of that particular experiment inside the `experiments/` directory and **copy all the contents of that folder** into your own local experiment folder.

This is important because some experiments contain multiple HTML files that are connected to each other. Copying only one file may cause the experiment to not work properly.

### Example: Experiment 3

If you want to write **Experiment 3**, go to:

```text
experiments/
└── exp-03-catalogue-page/
```

Copy **everything inside `exp-03-catalogue-page/`** to your own Experiment 3 folder.

The current Experiment 3 folder contains:

```text
exp-03-catalogue-page/
├── CATALOGUE.HTML
├── LOGIN.html
└── index.html
```

So your local Experiment 3 folder should contain all of these files:

```text
Experiment-3/
├── CATALOGUE.HTML
├── LOGIN.html
└── index.html
```

Then open the required HTML file in your browser and run the experiment.

### Steps

1. Open the `experiments/` folder.
2. Find the experiment you want to perform, such as `exp-03-catalogue-page`.
3. Open that experiment's folder.
4. **Copy all the files and folders inside it.**
5. Paste them into your own folder for that experiment.
6. Keep the same file structure and filenames.
7. Open the required `.html` file in a browser.
8. You can then modify the code according to your lab requirements.

### Experiments Available

```text
experiments/
├── exp-01-home-page/
├── exp-02-login-page/
├── exp-03-catalogue-page/
├── exp-04-cart-page/
└── exp-05-registration-page/
```

The same rule applies to **every experiment**: whenever you want to use an experiment, copy the **complete contents of its corresponding folder**, rather than copying an individual HTML file.

### Why Copy the Complete Folder?

An experiment may contain multiple HTML pages that are related to each other. Keeping all the files together preserves the required structure and allows the pages/links to work correctly.

> **In short:** Want to write Experiment 3? → Open `exp-03-catalogue-page` → Copy **everything inside the folder** → Paste it into your Experiment 3 folder → Open the required HTML file → Run it.
